# レベナビ かんたん使い方ガイド

このガイドは、パソコンやスマートフォンの操作に慣れていない方でも、レベナビを使えるように説明したものです。

むずかしい操作はありません。画面に書かれている順番どおりに進めれば大丈夫です。

## 1. レベナビでできること

レベナビは、ほかの宿の宿泊料金を見ながら、ご自身の宿の販売価格を考えるための道具です。

主に次のことができます。

- ほかの宿の宿泊料金を見る
- 料金が上がった日、下がった日を見る
- 予約サイトで部屋がなくなった日を見る
- ご自身で決めたA・B・C・Dなどの販売ランクから、参考にするランクを見る
- 3か月または6か月のカレンダーを見る

レベナビが予約サイトの販売価格を勝手に変更することはありません。最後に価格を決めるのは、お宿の方です。

## 2. はじめる前に用意するもの

次の3つをご用意ください。

1. 受信できるメールアドレス
2. 比べたい宿の予約ページ
3. ご自身の宿で使う販売ランクと価格

「予約ページ」とは、じゃらんや楽天トラベルなどで、宿の名前・料金・宿泊プランが表示されているページです。

販売ランクは、たとえば次のように決めます。

| ランク | 販売価格の例 |
|---|---:|
| A | 30,000円 |
| B | 22,000円 |
| C | 16,000円 |
| D | 10,000円 |

Aをいちばん高い価格にします。B、C、Dの順に少しずつ安くしてください。必要な場合はE、Fも追加できます。

## 3. アカウントを作る

### パスワードを使う場合

1. レベナビのログイン画面を開きます。
2. 「パスワード」を押します。
3. 「メールアドレス」に、ご自身のメールアドレスを入力します。
4. 「パスワード」に、8文字以上のパスワードを入力します。
5. 「新規登録」を押します。
6. 入力したメールアドレスに確認メールが届きます。
7. メールの中にある確認ボタンを一度押します。
8. レベナビへ戻り、メールアドレスとパスワードでログインします。

確認メールが見つからないときは、「迷惑メール」もご確認ください。

### メールのボタンだけでログインする場合

1. ログイン画面で「メールリンク」を押します。
2. メールアドレスを入力します。
3. 「メールでログインリンクを受け取る」を押します。
4. 届いたメールの中にあるログインボタンを一度押します。

この方法では、パスワードを入力しなくてもログインできます。

## 4. お支払いを確認する

画面に「月額プランを開始する」と表示された場合は、まだお支払いの確認が終わっていません。

- カード払いの場合は、「月額プランを開始する」を押して画面の案内に従います。
- 銀行振込の場合は、運営から案内された口座へお振り込みください。入金確認後、運営が利用できる状態にします。

銀行振込後すぐに画面が変わらない場合は、一度ログアウトしてから、もう一度ログインしてください。

## 5. 最初の設定をする

お支払いの確認後、「利用開始設定」が表示されます。

### 5-1. 施設名と住所を入れる

1. 「施設名」に、ご自身の宿の名前を入力します。
2. 「住所」に、ご自身の宿の住所を入力します。

### 5-2. 販売ランクを入れる

1. Aには、いちばん高い販売価格を入力します。
2. B、C、Dの順に、少しずつ安い価格を入力します。
3. EやFも使う場合は、「ランクを追加」を押します。

金額には、カンマを入れなくても大丈夫です。30,000円の場合は `30000` と入力できます。

### 5-3. 比べたい宿を登録する

まず、別の画面でじゃらんや楽天トラベルなどを開きます。

1. 比べたい宿のページを開きます。
2. 画面上部にある長い英数字の場所を一度押します。
3. 右クリックして「コピー」を押します。スマートフォンでは長押しして「コピー」を押します。
4. レベナビへ戻ります。
5. 「競合施設名」に、比べたい宿の名前を入力します。
6. 右側の入力欄を押して、「貼り付け」を押します。

通常プランでは、最大3施設まで登録できます。

最後に「設定を保存して分析を開始」を押してください。

## 6. 画面の見方

画面左側に4つのボタンがあります。スマートフォンでは画面下部に表示される場合があります。

### 概要

選んだ日の全体の様子を見る場所です。

- 「競合平均価格」：部屋がある競合施設の平均価格です。
- 「参考ランク」：ご自身で登録したランクの中から、参考にするランクを表示します。
- 「価格変動」：以前に取得した価格と比べて、どれくらい動いたかを表示します。
- 「部屋なしシグナル」：予約サイトで部屋なしと表示された競合施設の数です。

### 参考価格

選んだ日の参考ランクと、その理由を見る場所です。

表示された価格はあくまで参考です。そのまま販売価格にする必要はありません。

### 価格比較

競合施設ごとの価格を横に並べて見る場所です。

- 赤：以前より価格が上がっています。
- 青：以前より価格が下がっています。
- グレー：予約サイトで部屋なしです。

### カレンダー

日付ごとの価格と参考ランクを見る場所です。

日付を押すと、その日の詳しい理由が上の欄に表示されます。

## 7. 表示される言葉の意味

### 部屋なし

その予約サイトで、販売できる部屋が見つからない状態です。宿全体が必ず満室という意味ではありません。

### 残りわずか

予約サイトに「残り○室」などの表示があった状態です。

### 未取得

まだその日の情報を取りに行っていない、または取得できなかった状態です。料金が0円という意味ではありません。

### 履歴なし

比べるための過去の情報がまだない状態です。

前日比は翌日以降、先週比は7日後以降、先月比は30日後以降に少しずつ表示されます。

## 8. 表示する期間を変える

1. 「表示期間」を押して開きます。
2. 「3か月」または「6か月」を押します。
3. 画面が更新されるまで少し待ちます。

長い期間を選んでも、すべての日にすぐ価格が表示されるとは限りません。情報は毎日の取得によって少しずつ増えます。

## 9. 比べる時期を変える

「価格変動の比較基準」から選びます。

- 前日比：昨日取った価格と比べます。
- 先週比：7日前に取った価格と比べます。
- 先月比：30日前に取った価格と比べます。

同じ宿泊日の価格を比べます。今日泊まる料金と明日泊まる料金を比べる機能ではありません。

## 10. 設定を変える

左下の「設定」を押します。

設定画面では、次の変更ができます。

- A・B・C・Dなどの販売価格を変える
- 比べる宿を追加する
- 比べる宿の名前や予約ページを変える
- メール通知を受け取るかどうかを変える

変更後は、必ず画面右下の「変更を保存」を押してください。

## 11. パスワードを忘れたとき

1. ログイン画面で「パスワード」を押します。
2. メールアドレスを入力します。
3. 「パスワードを忘れた場合」を押します。
4. 届いたメールの中にあるボタンを押します。
5. 新しいパスワードを8文字以上で入力します。
6. 「保存する」を押します。

## 12. 困ったとき

### メールが届かない

- メールアドレスの入力間違いがないか確認します。
- 迷惑メールを確認します。
- 1分ほど待ちます。
- 短い時間に何度も押した場合は、しばらく待ってからやり直します。

### 価格が表示されない

- 「未取得」と書かれている場合は、まだ情報がありません。
- 予約ページの入力間違いがないか、設定画面で確認します。
- ページを再読み込みします。
- それでも表示されない場合は、施設名と表示されているメッセージを運営へお知らせください。

### 画面が動かない

1. 画面を再読み込みします。
2. 一度ログアウトします。
3. もう一度ログインします。
4. 直らない場合は、画面の写真を撮って運営へ送ります。

## 13. 毎日のおすすめの使い方

1. レベナビへログインします。
2. 今日から先の気になる日を選びます。
3. 競合平均価格と部屋なしシグナルを見ます。
4. 参考ランクと算出理由を見ます。
5. 前日比・先週比も確認します。
6. ご自身の予約状況と合わせて、販売価格を決めます。

参考ランクだけで決めず、実際の予約数、残り部屋数、地域の行事、連休なども合わせてご判断ください。
