# レベナビ クライアント向け想定質問

## データ取得について

### 毎日ログインしないと、価格は更新されませんか？

いいえ。レベナビは毎日午前9時と午後6時に自動で情報を取りに行きます。パソコンの電源を切っていても、ログアウトしていても動きます。

### 「表示を更新」を押すと、新しく予約サイトを調べますか？

いいえ。すでに保存されている最新結果を画面に読み直します。外部取得の回数は増えません。

### 「未取得」と「部屋なし」は同じですか？

違います。「未取得」は、その日の情報をまだ確認できていない状態です。「部屋なし」は、予約サイト上で販売できる部屋を確認できなかった状態です。未取得を0円や満室として扱うことはありません。

### ○・△・×は何を表していますか？

○は販売中、△は残室数や「残りわずか」の表示が確認できた状態、×は販売できる部屋を確認できなかった状態です。予約サイトが残室数を表示しない場合は、実際の残り部屋数までは分かりません。

### 予約サイトと価格が違うのはなぜですか？

取得時刻、人数、部屋タイプ、食事、税・サービス料の表示方法が違う可能性があります。同じ宿泊日・人数・条件で比較してください。それでも違う場合は、施設名、日付、予約サイト画面の画像を運営へお送りください。

### 90日すべてに価格が出ないことがありますか？

あります。宿がまだ販売を始めていない日、予約サイトが日付を出していない日、取得に失敗した日は「未取得」になります。価格を推測して埋めることはしません。

### 比較する宿には、どのURLを登録しますか？

検索結果や個別プランではなく、その宿の基本ページを登録します。楽天トラベルなら `https://travel.rakuten.co.jp/HOTEL/宿番号/宿番号.html` の形が基本です。プラン詳細URLは内容が変わったり終了したりするため、通常は使いません。

## 価格提案について

### 参考ランクはどう決まりますか？

部屋がある競合施設の最安値を集め、その平均に最も近い、自施設で登録した販売ランクを表示します。最低価格と最高価格の範囲も守ります。

### レベナビが予約サイトの販売価格を自動で変更しますか？

いいえ。現在は判断の参考を表示するだけです。販売価格は施設の担当者が確認して変更します。

### 前日比・先週比・先月比が表示されないのはなぜですか？

同じ宿泊日について、過去に取得した記録が必要だからです。導入直後は比較履歴がありません。毎日の取得が続くと、前日、先週、先月の順に比較できる日が増えます。

## アカウントと契約について

### パスワードを忘れた場合はどうしますか？

ログイン画面の「パスワード」を選び、「パスワードを忘れた場合」を押してください。届いたメールから新しいパスワードを設定できます。短時間に何度も押した場合は、画面に表示された時間だけ待ってください。

### メールが届きません。

迷惑メール、入力したアドレス、受信拒否設定を確認してください。数分待っても届かない場合は、登録メールアドレスと操作した時刻を運営へお知らせください。存在しないメールアドレスかどうかは安全のため画面に表示されません。

### 管理画面は誰でも見られますか？

いいえ。運営者として登録されたメールアドレスでログインした場合だけ表示されます。一般の施設アカウントにはメニューも表示されません。

### 銀行振込でも利用できますか？

はい。運営が入金を確認した後、利用期間を設定します。カード払いと違い、利用開始まで少し時間がかかる場合があります。

### 請求書や領収書は出せますか？

カード払いは契約管理画面の請求履歴から保存できます。銀行振込は入金確認後に運営へご依頼ください。

## 困ったとき

次の4点を運営へお知らせください。

1. 施設名
2. 登録メールアドレス
3. 問題が起きた日時
4. 画面全体の画像

パスワード、カード番号、メールに届いたログインリンクは送らないでください。
