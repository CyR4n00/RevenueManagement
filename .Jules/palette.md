## 2024-03-23 - Proper Use of defaultValue in React Forms\n**Learning:** React recommends using `defaultValue` on the `<select>` element instead of `selected` on individual `<option>` tags to set the initial value. Using `selected` on `<option>` tags leads to React console warnings, even if the HTML functions correctly.\n**Action:** Ensure that all uncontrolled select inputs use `defaultValue` at the parent `<select>` level rather than adding `selected` to child `<option>` elements.
