## 2025-02-23 - Form Accessibility Patterns in React Component Library
**Learning:** Found a recurring pattern where labels were used for visual styling but lacked programmatic association (`htmlFor`/`id`) with inputs. Additionally, `selected` attributes on `<option>` were creating React console warnings when `<select>` components should instead use `defaultValue`. Lastly, buttons toggling panel states needed `aria-expanded` and consistent keyboard focus indicators (`focus-visible`).
**Action:** When creating forms or settings panels, always start by matching `<label htmlFor="id">` to `<input id="id">` for proper screen reader support and clickable label areas. Use `defaultValue` on `<select>` wrappers instead of placing `selected` on children. Add `aria-expanded` and `focus-visible:ring-2` to interactive toggle buttons to ensure keyboard navigability and state communication.
