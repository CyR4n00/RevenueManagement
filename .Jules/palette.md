## 2026-06-20 - Accessible Form Inputs and React Defaults
**Learning:** In React, using the `selected` attribute on `<option>` tags within a `<select>` throws warnings. It is best practice to use `defaultValue` on the parent `<select>` element. Furthermore, all form inputs should have programmatic associations with their labels (using `htmlFor` and `id`) or use visually hidden labels (`sr-only`) to support screen readers, especially when considering audiences with low IT literacy. We also learned that `focus-visible:ring-2` provides critical keyboard navigation context.
**Action:** Updated `SettingsPanel.tsx` to use `defaultValue` on select tags, added `htmlFor` mappings across form inputs, and applied `focus-visible` classes globally on interactive controls like buttons and inputs.
