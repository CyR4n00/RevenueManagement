## 2024-06-25 - Explicit Label Association and Modal Accessibility
**Learning:** React specific issues were observed where `<select>` tags missing `defaultValue` and explicit `<label>` bindings can cause accessibility and build warnings. Modal close buttons frequently lack proper `aria-label` and `focus-visible` states, which are critical for keyboard and screen reader accessibility.
**Action:** Always use `htmlFor` on `<label>` elements linked to the `id` of corresponding `<input>` or `<select>` elements. Ensure icon-only buttons like `&times;` close buttons use `aria-label` and `focus-visible:ring-2` for keyboard support. On React `<select>` components, move the `selected` attribute from the `<option>` to the parent `<select>` as `defaultValue` to prevent React warnings.
