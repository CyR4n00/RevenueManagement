# レベニューコントロールシステム (MVP・初期フェーズ向け)

専任のレベニューマネージャーを配置できない小〜中規模宿泊施設（民泊、小規模ホテル）向けの、SaaS型レベニューマネジメント（収益最大化）システムです。

## 現在搭載されている機能（モック・プロトタイプ）

本プロトタイプは、商談・デモンストレーション向けに以下の機能を備えています。

1. **プラン別ロジック（Standard, Pro, Enterprise）**
   - **ルールベース価格調整**: 「稼働率が〇%以上なら価格を〇倍」というロジックを自動適用します（全プラン）。
   - **イベント上乗せ（Pro以上）**: 週末や地域のイベント（花火大会など）を検知し、価格に自動で倍率（例: 1.2倍）を上乗せします。
   - **AI自動予測（Enterprise）**: 過去の稼働実績や季節性データなどを機械学習（ランダムフォレスト）で学習し、最適な価格を自動算出します。
2. **安全装置（リミッター）**
   - システムが自動で価格を計算しても、事前に設定した「上限価格（max_price）」と「下限価格（min_price）」を絶対に超えないよう制御されます。
3. **インタラクティブなダッシュボード**
   - カレンダーで「別の日付」を選択すると、その日の予測稼働率が変動し、瞬時に価格が再計算されます。
   - 価格ルールを画面上でON/OFF（有効/無効）に切り替え、その場で価格変動をシミュレーションできます。
4. **効果検証ダッシュボード (PDCA)**
   - 過去の「目標収益」と「実際の収益」を比較するプログレスバーを表示し、システムの導入効果を検証できます。
5. **ゲスト向けウィジェット（モック）**
   - 予約サイトに埋め込むための「3段階の料金変動（おトク/通常/混雑）」ウィジェットをデモ表示し、価格変動へのゲストの不満（不公平感）を和らげます。

## システム構成・セットアップ

- **フロントエンド**: React, TypeScript, Tailwind CSS

## 起動方法（ワンクリック起動）

面倒なコマンド入力を省くため、一括起動スクリプトを用意しました。

### Mac / Linux の場合
ターミナルを開き、以下のコマンドを実行するだけです：
\`\`\`bash
./start.sh
\`\`\`

### Windows の場合
エクスプローラーから \`start.bat\` をダブルクリックするか、コマンドプロンプトで以下を実行してください：
\`\`\`cmd
start.bat
\`\`\`

起動後、自動的にバックグラウンドでサーバーが立ち上がります。
- 👉 **ダッシュボード**: http://localhost:3000
- 👉 **API ドキュメント**: http://localhost:8000/docs
