# Revenue Control System (レベニューコントロールシステム)

ホテル、民泊、レンタルスペースなどの宿泊・スペース貸しビジネスに向けた、自動価格調整（ダイナミックプライシング）システムです。
過去の予約データや現在の稼働率に基づき、ルールベースで最適な価格を自動算出し、売上の最大化（レベニューマネジメント）をサポートします。

## 主な機能
- **ダッシュボード**: 施設の現在の稼働率、売上予測、現在の価格をシンプルに可視化。
- **自動価格計算ロジック**: 稼働率、曜日、季節（イベント）に応じた価格の自動変動ルールを設定・適用。
- **設定UI**: BtoBユーザー（施設管理者）が直感的に価格ルールを調整できるインターフェース。
- **拡張性**: 初期はルールベースのアルゴリズムを使用しますが、将来的に蓄積されたデータを活用した機械学習（需要予測）モデルへの移行を見据えた設計になっています。

## データ連携手法の提案（クライアントへのヒアリング項目）

クライアントが利用しているPMS（宿泊管理システム）やサイトコントローラーとのデータ連携（空室状況の取得・新しい価格の反映）について、以下の方法が考えられます。クライアントの環境に合わせて最適なものを選択してください。

1. **API連携 (推奨)**
   - **概要**: サイトコントローラー（例: ねっぱん！、手間いらず、Beds24、Beds24 APIなど）やPMSが提供する公式APIを利用して、リアルタイムで在庫データの取得と価格の更新を行います。
   - **メリット**: リアルタイム性が高く、エラーが少なく最も安定的です。
   - **デメリット**: クライアントが利用しているシステムがAPIを公開している必要があり、利用に追加料金がかかる場合があります。

2. **CSV連携 (ファイルインポート/エクスポート)**
   - **概要**: PMS等からエクスポートした予約データ（CSV）をシステムに手動または自動（SFTP等）で取り込み、システムが算出した推奨価格リスト（CSV）をPMSにインポートします。
   - **メリット**: 多くのPMSがCSV出力に対応しているため、汎用性が高く導入が容易です。
   - **デメリット**: リアルタイム性に欠け、手動運用の場合はオペレーションの負担が増えます。

3. **RPA / Webスクレイピング連携**
   - **概要**: 自動化プログラム（SeleniumやPlaywrightなど）を用いて、システムが管理画面のブラウザ操作を代行し、在庫の読み取りや価格の入力を自動で行います。
   - **メリット**: APIがない古いシステムや独自のシステムでも無理やり連携させることが可能です。
   - **デメリット**: システム側のUI変更によりスクリプトが動かなくなるリスク（保守コストが高い）があります。

4. **iCal (iCalendar) / Webhook連携**
   - **概要**: 予約発生時にiCal形式のカレンダー同期やWebhookを利用して、在庫変動のみを即座に検知し、価格調整トリガーとして利用します。（価格の更新自体は他の手法を併用）
   - **メリット**: 民泊系プラットフォーム（Airbnbなど）で標準サポートされており、手軽に在庫把握が可能です。

## システム構成・技術スタック

- **バックエンド**: Python, FastAPI
- **フロントエンド**: React, TypeScript, Tailwind CSS
- **データベース**: SQLite (初期構成用。本番運用時はPostgreSQLやMySQLへ移行可能)

## セットアップと起動方法

### バックエンドの起動
\`\`\`bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload &
\`\`\`
※ APIドキュメントは `http://localhost:8000/docs` で確認できます。

### フロントエンドの起動
\`\`\`bash
cd frontend
npm install
npm start &
\`\`\`
※ アプリケーションは `http://localhost:3000` で確認できます。
