# レベニューコントロールシステム (MVP・初期フェーズ向け)

専任のレベニューマネージャーを配置できない小〜中規模宿泊施設（民泊、小規模ホテル）向けの、SaaS型レベニューマネジメント（収益最大化）システムです。

## 解決する課題
1. 過去データの抽出や外部要因チェックにかかる膨大な時間と手間（工数負荷）の削減。
2. ベテランスタッフの「経験と勘」による属人化・ブラックボックス化の解消。

## ビジネスモデル
「プラン別月額基本料」＋「客室数に応じた段階的料金」の定額制サブスクリプション。

## 提供プラン
- **スタンダードプラン（基本・業務効率化）**: 空室率に応じた自動価格調節、1日1回のOTA同期。
- **プロプラン（中級・差別化戦略）**: 地域の資産（イベント等）による上乗せ処理、リアルタイム同期。
- **エンタープライズプラン（最上位・完全自動化）**: 機械学習を用いた需要予測による完全自動化とパーソナライズ。

## 主要機能モジュール
1. **データ収集・統合**: 自社実績データ、外部環境データ（イベント・季節・気象）、競合データの統合。
2. **ダイナミックプライシング・エンジン**: 空室率や外部要因に基づく「ベストアベイラブルレート」の算出。
3. **OTA・サイトコントローラー連携**: 算出された価格の自動連動。
4. **効果検証ダッシュボード (PDCA)**: 目標収益と実際の収益の比較検討。

## 安全要件（リスクヘッジ機能）
- **安全装置（リミッター）**: 異常な価格変動を防ぐ上限価格・下限価格の設定。
- **オーバーブッキング防止**: システム制御による過剰な予約のブロック。
- **ゲスト向けUI（価格透明性の確保）**: 自社予約サイト等で価格が3段階で変動することを明示するウィジェット。

## システム構成・セットアップ
- **バックエンド**: Python, FastAPI, scikit-learn (Machine Learning)
- **フロントエンド**: React, TypeScript, Tailwind CSS

### バックエンドの起動
\`\`\`bash
cd backend
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload &
\`\`\`

### フロントエンドの起動
\`\`\`bash
cd frontend
npm install
npm start &
\`\`\`
